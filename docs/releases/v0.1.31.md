# Release v0.1.31

**Portable identities for inference paths, a deny-by-default application
control contract, and a verified development toolchain.**

## Overview

v0.1.31 adds two proposed portable contract families. The inference path
taxonomy names parties, model families, exact source-native model pins, and
declared routes without confusing declarations with runtime observations. The
application control family defines a typed seam for discovering, observing,
and operating an application while keeping its hosted content sessions outside
the control boundary.

The release also rotates the committed OpenPGP release-key pin and aligns local
bootstrap and hosted checks on sfetch v0.4.12 and Goneat v0.6.0.

## Highlights

### Inference path taxonomy

`inference-path-taxonomy/v0` provides closed schemas for parties, model
families, model pins, and path identities. Its examples, rejects, and semantic
controls preserve source-native identifiers and prevent a declared route from
being presented as an observed effective route, health result, or billing
identity.

### Application control and observation

`application-control/v0` standardizes application discovery, operation and
information-source catalogs, replay-safe request/result messages, observations,
and evidence across interaction, authorization decision, and effect stages.
Authorization inputs are deny-by-default, caller-supplied principals are
rejected, and content sessions hosted by the application remain out of scope.

The family includes schemas, conforming and negative fixtures, semantic
controls, a reader-facing standard, and three proposed decision records:
ADR-0010 for the contract boundary, DDR-0001 for the data contract, and
SecDR-0001 for controller authority.

### Release-signing key rotation

`docs/security/release-signing-keys.asc` now contains the current public key
used to verify release tags. The key remains committed so the verification
input is reviewable with the release source.

### Verified development toolchain

Development bootstrap now installs sfetch v0.4.12 through an immutable,
digest-checked verification engine and asserts the repo-local binary version.
That verified sfetch installs the pinned Goneat v0.6.0 release with minisign
required. Check and release workflows move to the v0.5.6 glibc tools runner,
which carries Goneat v0.6.0.

The release workflow continues to require a valid annotated-tag signature and
the publication-policy attestation before it publishes a release.

## Compatibility

Both new families are proposed `v0` contracts. Consumers should pin the exact
reviewed repository revision and artifact digests; incompatible changes may
still occur before promotion to a stable family version. Existing contract
families and document formats are unchanged.
