# Release v0.1.32

**Experimental immutable snapshots, enforced attribution footers, and native
contract validation.**

## Highlights

### Segmented snapshots

The proposed, experimental `segmented-snapshot/v0` companion to data-artifact
defines a flat, self-contained immutable snapshot for one grain and
representation. Publication, manifest, profile and verification schemas are
accompanied by semantic controls, conformance cases, ADR-0011 and DDR-0002.

Exact stored-byte bindings, bounded reference graphs and scope-specific
verification results do not establish authentication, authorization, runtime
custody or crash durability. Production adoption requires separate evidence.
Live append, WAL and paging protocols remain outside this initial contract.

Data-artifact guidance distinguishes lifecycle outcomes, publication, source
coverage and representation guarantees without changing its schema fields.

### Attribution checks

Commit messages and PR bodies end with the required three-line attribution
footer. The repository supplies a checker, commit-message hook, composite action
and reusable workflow. Current documentation and all seven role-example files
use the same cross-organization format, with a bare public role slug and
`Committer-of-Record: @3leapsdave`. Historical release records are unchanged.
Human maintainer accountability remains explicit.

### Native validation and toolchain

Required CI combines full repository quality on Linux with native contract
validation on Linux amd64/arm64, Darwin arm64 and Windows amd64/arm64. The
aggregate fails closed if a required job is missing or unsuccessful. Darwin
amd64 is unsupported.

Goneat is pinned to v0.6.1; the glibc tools runner is pinned to v0.5.7 and consumed
by immutable digest. Windows arm64 builds the pinned Goneat source using verified
module checksums and a pinned compiler, reporting its development-build identity.
Native contract checks do not require identical maintainer formatter stacks on
every platform. Immutable image consumption is not an authentication claim.

### Project management prompt

The draft `projectmgr` role emphasizes inspectable delivery state, gated
completion, precise residuals and explicit authority for irreversible actions.
No project methodology is required; `deliverylead` remains deprecated in favor
of `projectmgr`.

## Compatibility

The segmented-snapshot bundle remains proposed and experimental; this release
does not promote it to stable or certify an adopter. Existing data-artifact
producers need not adopt a new storage protocol. Other schema-family versions
are unchanged.
