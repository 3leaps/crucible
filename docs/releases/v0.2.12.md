# Release v0.2.12

**Date:** 2026-11-14

**Adds draft secret-surface boundaries and extends library implementation profiles and qualification-harness rules.**

## Highlights

- The [secret-surface standard](../standards/secret-surface-boundaries.md)
  and [SecDR-0002](../decisions/SecDR-0002-secret-surface-non-disclosure-and-input-isolation.md)
  define value-free control, observation, MCP and graphical surfaces, explicit
  secret input ports, local CLI/TUI output custody, child and helper boundaries,
  protected file outputs and adopter non-disclosure controls.
- [Repository classes 0.1.2](../standards/repository-classes.md) and
  [ADR-0018](../decisions/ADR-0018-prims-multi-language-commitment.md) extend
  Profile A/B adoption to unsuffixed library+CLI toolkits, document legacy Go
  module cutover and Rust-generated native/WebAssembly TypeScript delivery,
  and retain shared conformance requirements for native Rust/Go twins.
- Qualification harnesses require independent pack authority for retained-run
  verification, contained subject execution, and separate correctness,
  containment, migration-divergence and telemetry results.

## Adoption notes

The secret-surface standard (0.1.0) and repository-classes standard (0.1.2)
remain draft; SecDR-0002 and ADR-0018 remain proposed. Pin an exact release or
commit when adopting these documents.

Explicit caller-named environment inputs and local CLI reveal/export outputs
are separately bounded local data-plane paths. They do not authorize control,
MCP or graphical adapters to receive or forward secret values. Adopters must
verify their own input, output, helper and child-process custody controls.

Repository declarations and class checks remain manual while the planned
taxonomy schema and checker are unshipped. This release changes documentation;
it does not qualify an existing secret-handling product, language binding or
qualification harness.

## What a release carries

A Crucible release is a GPG-signed annotated Git tag. It publishes no assets,
so there are no `SHA256SUMS` or `SHA512SUMS` files to verify. See
[release security](../security/README.md).
